# Migration attribution

The content, recipe data, photographs, logos, and static presentation were
migrated from The Healthy Malteser at the site owner's request. The original
rendered presentation contains styling generated by Astra, Gutenberg, Spectra,
and WP Recipe Maker. Their static CSS selectors are retained to preserve the
existing design. No PHP, WordPress installation, CMS service, plugin JavaScript,
or third-party recipe runtime is included in the migrated application.

PT Sans is served locally in WOFF2 format. Its license is in `licenses/PT-Sans.txt`.
